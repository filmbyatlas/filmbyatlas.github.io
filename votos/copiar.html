Código del servidor

Pulsa el botón y el código se copiará entero.

Después, desde el móvil:
  1. En Chrome, abre script.new, pulsa los tres puntos ⋮ y activa Sitio de escritorio (el editor de Google no funciona bien en vista móvil).
  2. Mantén pulsado dentro del editor → Seleccionar todo → Pegar. Guarda con el icono del disquete.
  3. Implementar → Nueva implementación → engranaje → Aplicación web. Ejecutar como: Yo. Acceso: Cualquier usuario. Implementar y autorizar.
  4. Copia la URL que termina en /exec y mándasela a Claude.

Si el botón no funciona, mantén pulsado el texto de abajo → Seleccionar todo → Copiar.
