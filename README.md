# ¿A quién votarías?

Test político de 30 afirmaciones: https://filmbyatlas.github.io/votos/

Los resultados de cada grupo se guardan cifrados (AES-256-GCM) en jsonblob.com. La clave va en el fragmento del enlace del grupo (`#g=…&k=…`) y nunca se envía a ningún servidor, así que este repositorio no contiene ningún dato.
